# Link registry of the product (S4CORE, CONTRACT) - CDS snippets

> Generated by `tools/link_registry.py` - never edit, regenerate. `To` is the alias of the target, `From` of the source; a payment model mapping names the link (`{"link": ...}`) and gets the join rendered with its own aliases. A transform renders as a CDS function (VERIFY-ADT on the release before a generated view uses one). PREFER is not a join condition: the consumer view applies it (e.g. a status filter or the newest row).

Journal entry line -> its journal entry - N1, quality C, inactive (VERIFY) V110.

                                     and To.FiscalYear         = From.FiscalYear
                                     and To.AccountingDocument = From.AccountingDocument

  on _JournalEntry.CompanyCode = $projection.CompanyCode
