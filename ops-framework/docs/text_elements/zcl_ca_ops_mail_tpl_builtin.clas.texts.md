# ZCL_CA_OPS_MAIL_TPL_BUILTIN — text elements (class text pool)

Labels of the standard business-context keys in the built-in layout of the alert e-mail (the same
labels as the generic template `ZCA_OPS_ALERT_DEFAULT`, `templates/zca_ops_alert_default.md`). A key
that is blank for a message is not shown.
